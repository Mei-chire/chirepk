# Chirepk

Chirepk 是一个用 Go 实现的初中自动排课应用。当前版本保留八年级 801–821 班级骨架与默认作息，任课数据需要从 Excel 导入；不接数据库，配置修改和排课记录只保存在服务进程内存中。

## 运行

需要 Go 1.22 或更高版本：

```bash
go run .
```

浏览器打开 <http://localhost:8080>。也可以指定监听地址：

```bash
go run . -addr :8090
```

## 已实现

- 每周五天与可编辑的默认作息
- 从 Excel（.xlsx）导入班级、教师和课时，政治自动归一为道法
- 未导入时任课设置和教师统计保持空白，导入后按 Excel 中的实际班级数量展示
- 每班周课时容量按“每周天数 × 每天可排课时段数”动态计算
- 社团、劳技、安全按无教师课程处理
- 导入后必须分别保存每日作息和任课设置，后端才允许开始排课
- 21 个班的课程增删，以及教师、普通课时、连堂次数编辑
- 教师周课时和带班统计
- 异步排课任务与进度展示
- 教师同一时段不冲突
- 连堂课不跨上午、下午
- 第九节数学 2 节，语文、英语、物理各 1 节
- 排课记录卡片、班级课表和教师行程查询
- 生成后独立校验课时、连堂、第九节配额和教师冲突
