# Chirepk

Chirepk 是一个使用 Go 编写的本地 Web 自动排课工具，面向需要按班级、课程、教师和作息生成周课表的教学管理场景。应用提供 Excel 导入、任课与作息编辑、自动排课、约束校验、课表查询和 Excel 导出能力。

> 本项目仅提供通用功能和脱敏示例。README、示例文件、测试数据和提交记录中不得出现真实学校名称、教师姓名、学生信息、联系方式或其他可识别的业务数据。

## 架构与目录

项目按前后端和职责边界组织：

```text
backend/
├── cmd/chirepk/                 # 服务启动入口
└── internal/
    ├── domain/                 # 领域模型、默认配置和配置校验
    ├── application/            # 导入、排课、导出和课表调整等用例
    ├── scheduler/              # 排课约束求解和课表调整算法
    ├── store/                  # Repository 接口与内存实现
    ├── adapter/xlsx/           # Excel 文件适配器
    └── transport/http/         # HTTP 路由、请求解析和中间件
frontend/
├── embed.go                    # 前端资源嵌入边界
└── static/                     # HTML、CSS、JavaScript 和静态资源
```

HTTP 层只处理协议，业务流程由 `application.Service` 编排；排课算法、领域模型和存储实现均可独立替换或测试。

## 功能概览

- 从 `.xlsx` 文件导入班级、教师和课程课时；支持常见的课程名称别名。
- 编辑每周五天的作息安排，并标记哪些时段参与排课。
- 按导入文件中的班级数量动态生成任课设置和课时统计。
- 支持普通课时、连堂次数和无教师课程的配置。
- 异步生成课表，并显示排课进度和任务记录。
- 检查教师时间冲突、课时数量、连堂结构、专项时段配额和课程分布。
- 查询班级课表与教师行程，支持在约束允许的范围内微调课表。
- 将已完成且通过校验的结果导出为 Excel 工作簿。

## 隐私与数据处理

- 导入前请将学校、年级、班级、教师等字段替换为不可识别的代号，例如 `示例班级 A`、`教师甲`。
- 代码内置的默认配置仅用于测试和演示，使用 `示例学校`、`示例班级` 和 `示例教师` 等合成占位符。
- 不要把包含真实个人信息的 Excel、导出课表、截图或日志提交到版本库，也不要在问题描述中粘贴原始数据。
- 服务默认使用内存存储。导入配置和排课记录仅在当前进程中存在，进程重启后会清空；上传文件名可能在进程内显示，请使用脱敏文件名。
- 当前版本没有登录、权限控制、审计和持久化能力，适合本地开发或受控环境演示，不应直接部署到公网。

## 环境要求

- Go 1.22 或更高版本
- 支持现代 JavaScript 的浏览器
- 一个不超过 20 MB 的 `.xlsx` 任课表文件（如需导入）

## 快速开始

在仓库根目录执行：

```bash
go run ./backend/cmd/chirepk
```

默认监听 `localhost:8080`，然后访问 <http://localhost:8080>。

可以通过命令行参数修改监听地址：

```bash
go run ./backend/cmd/chirepk -addr :8090
```

程序也支持 `PORT` 环境变量。例如，在 PowerShell 中执行 `$env:PORT = "8090"; go run ./backend/cmd/chirepk`，在 macOS/Linux 中执行 `PORT=8090 go run ./backend/cmd/chirepk`。

也可以先构建再运行：

```bash
go build -o chirepk ./backend/cmd/chirepk
./chirepk -addr :8080
```

## Excel 导入格式

导入器读取所有未隐藏的工作表，并使用以下约定：

- `任课课时汇总` 工作表必须存在；包含“任课”与“课时”的工作表名称均可识别。
- `每日作息` 工作表必须存在，并用于设置当前导入任务的作息。
- 任课表的字段标题行可位于前 20 行，标题行之后是班级数据。
- A 列为年级，B 列为班级标识，D 列为班主任。
- 每个课程占两列，第一列为任课教师，紧邻的下一列标题必须为 `课时`。
- 每日作息表需要包含 `时段安排`、`开始时间`、`结束时间` 和 `排课属性` 四列；排课属性填写 `可排课` 或 `不排课`。
- 课时单元格可填写普通课时，例如 `4`，或填写“普通课时+连堂次数”，例如 `4+2`。
- 支持的课程包括语文、数学、英语、道法（政治等名称会归一化）、历史、地理、生物、物理、化学、音乐、美术、体育、社团、劳技和安全。
- 社团、劳技和安全按无教师课程处理。空白课时按 `0` 处理。

示例（仅使用占位符，不能替换为真实数据）：

| A 列 | B 列 | D 列 | E 列 | F 列 |
| --- | --- | --- | --- | --- |
| 年级 | 班级标识 | 班主任 | 语文 | 课时 |
| 示例年级 | 示例班级 A | 教师甲 | 教师乙 | 4+1 |

实际工作簿需要为每个课程继续提供“教师列 + 课时列”组合；列顺序可以根据模板调整，但标题和相邻关系必须保持一致。

## 使用流程

1. 启动服务并打开首页。
2. 导入已经脱敏的任课 Excel。
3. 检查每日作息，保存作息设置。
4. 逐班检查教师和课时，保存任课设置。
5. 在“开始排课”页面创建任务，等待生成完成。
6. 查看自检报告、班级课表和教师行程；必要时使用课表微调。
7. 导出课表，并按数据管理要求及时清理包含业务数据的文件。

## HTTP 接口

前端使用同源 JSON API，主要接口如下：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| `GET` | `/api/health` | 健康检查 |
| `GET` / `PUT` | `/api/config` | 读取或保存配置 |
| `POST` | `/api/config/reset` | 恢复空白配置 |
| `POST` | `/api/import/xlsx` | 导入任课 Excel |
| `GET` | `/api/teachers` | 获取教师课时统计 |
| `GET` | `/api/preflight` | 检查是否具备排课条件 |
| `GET` / `POST` | `/api/runs` | 查询或创建排课任务 |
| `GET` | `/api/runs/{id}` | 查看排课详情 |
| `GET` | `/api/runs/{id}/adjustment-candidates` | 获取可用的课表微调方案 |
| `POST` | `/api/runs/{id}/adjustments` | 应用课表微调 |
| `POST` | `/api/runs/{id}/adjustments/undo` | 撤销最近一次微调 |
| `GET` | `/api/runs/{id}/export.xlsx` | 导出课表 |
| `DELETE` | `/api/runs/{id}` | 删除已结束的排课记录 |

## 已知限制

- 当前版本固定为每周五个教学日；可排课容量由作息中标记为“纳入排课”的时段动态计算。
- 仅支持 `.xlsx` 导入，不读取隐藏工作表。
- 服务默认无认证和访问控制，请在可信网络或本机使用。
- 排课结果和配置不会自动写入磁盘；需要长期保存时请导出结果，并自行按隐私规范管理文件。
